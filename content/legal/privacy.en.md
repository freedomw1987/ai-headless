# ai-headless Privacy Policy

**Last updated**: September 5, 2026
**Version**: 1.0.0

## 1. Data We Collect

- **Account data**: email, name (optional), password (hashed)
- **Usage data**: API calls, chat conversations, extension settings
- **Technical data**: IP address, user agent, request ID (for debugging)

## 2. How We Use Data

- Provide and improve the Service
- Security monitoring (Sentry error tracking)
- Customer support
- Legal compliance

**We do not sell your data to third parties.**

## 3. Data Retention

- Account data: deleted within 30 days of account deletion
- Usage data: retained for 12 months (debugging & improvement)
- Chat conversations: retained for 90 days

## 4. Third-Party Services

We use:

- **Vercel / Neon** (hosting + database)
- **Sentry** (error monitoring)
- **Resend / nodemailer SMTP** (email delivery)
- **OpenAI / Anthropic** (AI providers, using your API key)

These services may receive necessary technical data.

## 5. Your Rights

You have the right to:

- Request access to your data
- Correct inaccurate data
- Delete your account and data
- Export your data (JSON format)
- Withdraw consent

Contact privacy@ai-headless.local to exercise rights.

## 6. Cookies

We use:

- **Essential cookies**: session, csrf token
- **Analytics cookies**: none
- **Advertising cookies**: none

## 7. Security

- Passwords hashed with bcrypt
- HTTPS for all transmission
- CSRF token protection (Sprint 57)
- Request ID correlation for logs and errors

## 8. Policy Changes

Material changes will be communicated 30 days in advance via email.

## 9. Contact

Privacy inquiries: privacy@ai-headless.local
